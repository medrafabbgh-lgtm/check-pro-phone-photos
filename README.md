# Check Pro phone photos

Small phone photos (WebP, about 160×212) that the Check Pro shop app shows on its repair cards,
so the shop sees the customer's phone at a glance.

- `v1/<name>.webp`: one photo per phone model
- `index.json`: phone model names → photo file

Source: product thumbnails from GSMArena.com. The photos belong to their owners.
If you own one of these photos and want it removed, please open an issue.
